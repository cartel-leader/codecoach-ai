# ⚔️ CodeCoach AI — DSA Interview Practice Platform

An AI-powered coding interview preparation platform with 40+ DSA problems, a VS Code-grade editor, and an AI reviewer that roasts your code like a strict interviewer.

## Features

- 🧠 **40+ DSA Problems** — Arrays, Strings, Trees, Graphs, DP, Heap, Stack, Recursion and more
- ⚔️ **Monaco Editor** — Same editor engine that powers VS Code, right in the browser
- 🤖 **AI Code Reviewer** — Reviews your solution for correctness, time complexity, space complexity, and style
- 📂 **Category Filter** — Browse problems by topic
- 🎯 **Difficulty Levels** — Easy, Medium, Hard with color coding

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Monaco Editor (@monaco-editor/react)
- Claude AI API (Anthropic)
- Vercel (Deployment)

## Run Locally

npm install
npm run dev

Open http://localhost:3000
